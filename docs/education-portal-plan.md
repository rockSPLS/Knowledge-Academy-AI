# План реализации

Разработка идёт итерациями: каждая итерация заканчивается работающим результатом, который можно открыть и проверить в браузере.

Статусы: ⬜ не начато · 🔄 в работе · ✅ готово

- [x] Тексты статей перенесены в MDX

- [x] Первый компонент в статье (inline-режим)

- [x] ⚑ Система оценки (частично верные ответы)

- [x] ⚑ Базовый дизайн

## Итерация 4. Собственный и продвинутые компоненты ✅

Идут раньше контента: собственный тип — самая непредсказуемая часть работы, а продвинутые упражнения привязаны к конкретным статьям — их место нужно знать до наполнения статей.

- [x] ⚑ Собственный тип упражнения: идея («Цена выбора»)
- [x] Собственный тип: реализация
- [x] ⚑ Продвинутое упражнение на применение навыка: делаем ли, какое и как оцениваем — «Улучшите промпт» (сделано после основного)
- [x] Продвинутое упражнение: реализация
