# Расширение: путешествие по знаниям

Пользователь вводит тему или вставляет текст — языковая модель разбирает материал и строит путешествие: последовательность чекпоинтов — остановок с упражнениями по одной части материала. Путешествие проходят на время, а в конце получают отчёт с результатами по каждому чекпоинту. Упражнения первой версии портала переиспользуются, к ним добавляются свободные ответы с оценкой моделью и новый собственный тип.

## Итерация 7. Подключение языковой модели ✅

- [x] ⚑ Серверный модуль вызова модели: модель меняется одной настройкой, ответ проверяется по схеме. Образец `.env.example` с адресом, ключом и моделью (исключение для него в `.gitignore`)
- [x] Пробный запрос к модели
- [x] Запуск без ключа или при недоступной модели: сервер отвечает понятной ошибкой «генерация недоступна», остальной сайт работает
- [x] Защита: ограничение длины текста
- [x] ⚑ Лимит частоты запросов к модели: где хранить счётчик (у серверных функций на хостинге нет общей памяти между вызовами)

## Итерация 8. Генерация путешествия ✅

- [x] ⚑ Устройство промптов: единица знания (одна мысль или понятие, которое проверяют упражнения), размер чекпоинта, порядок по зависимостям, неочевидные вопросы и правдоподобные неверные варианты, разнообразие типов, подсказки, рост сложности
- [x] ⚑ Структура данных и хранение путешествия (как и в первой версии портала, правильные ответы не попадают в браузер до раскрытия); решать вместе с хранением счётчика лимита из итерации 7
- [x] Генерация: проверка той же функцией `validateExercise`, что и у упражнений банка, повтор при ошибке, защита от инъекции промпта во вставленном тексте
- [x] Пример путешествия, составленный вручную, и сохранённые ответы модели — разработка и проверки без лишних запросов к модели
- [x] Защита маршрута генерации: ключ лимита по сети IPv6 /64, проверка размера запроса до чтения
