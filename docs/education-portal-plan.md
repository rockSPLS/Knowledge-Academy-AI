# Расширение: путешествие по знаниям

Пользователь вводит тему или вставляет текст — языковая модель разбирает материал и строит путешествие: последовательность чекпоинтов — остановок с упражнениями по одной части материала. Путешествие проходят на время, а в конце получают отчёт с результатами по каждому чекпоинту. Упражнения первой версии портала переиспользуются, к ним добавляются свободные ответы с оценкой моделью и новый собственный тип.
