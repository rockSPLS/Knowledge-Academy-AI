## Итерация 1. Поиск по материалам портала

**Статус:** ⬜

**Цель:** на вопрос о материалах портала — ответ модели по найденным фрагментам статей с источниками-ссылками на разделы; без модели — найденные фрагменты по словам.

### План

- [ ] Эмбеддинги через OpenAI-совместимый сервис: проверка на нескольких фрагментах до остальной работы
- [ ] Якоря у разделов статей — ссылка-источник ведёт прямо на раздел
- [ ] Скрипт индексации: разделы статей и упражнения → эмбеддинги → JSON-индекс; пересчёт только изменившихся фрагментов
- [ ] Поиск по смыслу и по словам; без модели — только по словам
- [ ] Ответ модели по найденным фрагментам с источниками; у упражнений — вопрос и ссылка на раздел, без объяснения верного ответа
- [ ] Набросок: где на сайте поиск и как показан ответ — раскладка по выбранному наброску
- [ ] Защита: лимит частоты, длина вопроса, проверка ввода схемой, защита от инъекции промпта
- [ ] Сохранённые ответы модели — разработка и проверки без лишних запросов к модели
- [ ] Промпт ответа — в журнале промптов
- [ ] Самопроверка: типы, линтер, сборка, браузер (в том числе узкий экран, светлая и тёмная тема), CRLF

## Итерация 2. Прогресс и сохранённые путешествия

**Статус:** ⬜

**Цель:** портал помнит ответы, время и путешествия человека, поиск учитывает его результаты, а человек может посмотреть, выгрузить и удалить свой прогресс.

### План

- [ ] Сохранение ответов на упражнения в статьях и в итоговом тесте; итоги путешествий; темы ответов
- [ ] Время: на статьях — пока вкладка открыта и активна, в тесте и путешествиях — время прохождения
- [ ] Несколько сохранённых путешествий; их фрагменты — в поиске
- [ ] Поиск учитывает результаты: объяснения упражнений, на которые человек уже ответил, и где он ошибся
- [ ] Страница прогресса: какие темы усвоены и какие стоит повторить, время, выгрузка в файл, удаление всего прогресса, выключатель, который разрешает или запрещает использовать прогресс в ответах модели, что уходит модели
- [ ] Короткая сводка прогресса для запросов к модели
- [ ] Самопроверка: типы, линтер, сборка, браузер (в том числе узкий экран, светлая и тёмная тема), CRLF

## Итерация 3. Разбор ошибок: что повторить

**Статус:** ⬜

**Цель:** по кнопке — разбор ошибок человека и что повторить, со ссылками на разделы и упражнения.

### План

- [ ] Разбор по сводке прогресса и найденным фрагментам, ответ строго по схеме
- [ ] Ссылки на разделы статей и упражнения
- [ ] Без сохранённого прогресса или без модели — понятное сообщение
- [ ] Промпт разбора — в журнале промптов
- [ ] Самопроверка: типы, линтер, сборка, браузер (в том числе узкий экран, светлая и тёмная тема), CRLF

## Итерация 4. Путешествие по теме из материалов портала

**Статус:** ⬜

**Цель:** путешествие по теме, собранное из найденных фрагментов портала с учётом тем, которые человеку стоит повторить; у чекпоинтов — источники, составленное ИИ отмечено, путешествие сохраняется.

### План

- [ ] Тема → поиск фрагментов → генерация путешествия на их основе с учётом тем, которые стоит повторить
- [ ] Источники у чекпоинтов, ярлыки, которые отличают материалы портала от составленного ИИ
- [ ] Сохранение и фрагменты нового путешествия в поиске
- [ ] Из разбора ошибок — путешествие по теме, которую стоит повторить
- [ ] Промпт генерации по теме — в журнале промптов
- [ ] Самопроверка: типы, линтер, сборка, браузер (в том числе узкий экран, светлая и тёмная тема), CRLF
